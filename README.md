# 截止线 · Deadline Desk

> 本地截止日期桌面工作台 —— 打开电脑一眼看清「哪些作业快到期、哪些已逾期」，不用再反复登录各种网站查截止日期。

面向学生的 **Windows 本地桌面应用**：记录课程大作业（硬性截止、个人 / 团队、中间状态）和想完成的活动（软性目标），数据全部存在本机，不联网、不需要账号。

## 功能特性

- **「今天要处理」置顶区**：今天到期 / 已逾期的条目自动置顶，打开就看到
- **状态流转**：未开始 → 进行中 → 已完成，大作业支持中间状态
- **桌面小组件**：独立置顶小窗常驻桌面，随时瞄一眼
- **系统托盘 + 本地通知**：临近截止自动提醒
- **备份与恢复**：数据库 + 附件打包导出 / 导入（zip）
- **NSIS 安装包**：electron-builder 打包，双击安装

## 技术栈

Electron 28 · sql.js（SQLite，纯 JS 实现、免原生编译）· 原生 HTML / CSS / JS 渲染层 · electron-builder

数据存放在系统用户数据目录（`userData/deadline-desk.db` + 本地附件目录），300ms 防抖持久化。

## 开发

```bash
npm install
npm start
```

## 打包

```bash
npm run build      # 输出 NSIS 安装包到 dist/
npm run pack       # 仅打包目录，不生成安装器
```
